# HK Flood Lab · 香港洪涝实验室（公开演示）

这是 HK Flood Lab 的静态演示构建：在浏览器里用 GPU（WebGL2）实时求解二维浅水方程，重演香港历史上的几场大洪水（1962 温黛、2017 天鸽、2018 山竹、2023 黑雨）以及一个虚构的千年一遇台风情景，可加措施做 A/B 对比，并与报道的水浸记录逐点比较。

演示地址：https://jumbokun.github.io/hk-flood-lab-demo/

需要支持 WebGL2 的桌面浏览器（Chrome / Edge / Firefox / Safari 17+）；每个场景约 25–50 MB 数据，首次加载需要一点时间。

## 数据来源

* 地形：土木工程拓展署 2020 年机载 LiDAR（0.5 m）与地政总署 5 m 数字地形模型（香港特别行政区政府开放数据）
* 潮位与雨量：香港天文台（验潮站记录、逐时/逐日雨量、热带气旋报告）
* 雨水排放系统：渠务署（空间数据共享平台 CSDI）
* 建筑、水系、设施：Overture Maps Foundation（含 OpenStreetMap 贡献者数据，ODbL）
* 底图与影像：© 地政总署，香港特别行政区政府（香港地理数据站地图 API）
* 水浸记录：天文台事件报告、区议会文件与新闻报道（见应用内验证表的来源列）

本演示仅供研究与展示，模拟结果不是官方洪水风险评估。地下空间容量、历史地形等为估计值；验证点的报道深度为半定量描述。
